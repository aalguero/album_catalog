The idea is to accelerate the creattion and maintenance of a catalog of my records. With 1000s of albums to process this is a tedious data entry task so the app is intended to make this easier.

Here are some aspects of the specification. The rest you should interview me to get more detail or clarify anything.

-this is an android app that will run natively on a pixel10 pro XL
-I am unsure what the optimal programming language choice is. I am flexible so help me choose
-we are developing on a debian computer with access to a local postgres database
-use the phone camera to scan an album's cover, spine, or vinyl label to gather metadata about the physical album. 
-We will need to findthe most accurate matching methods keeping in mind that the less work it is to scan an album the better. minimize taking multiple pictures or having to take the physical vinyl out of the record sleeve 
-use scanned metadata to query a reliable online music catalog source like discogs to match the metadata with an album
-for multiple matches, rate the quality of each match and select the top 3 for presentation to the user to select the preferred match
-Update the catalog using the matched album data from the matched online source
